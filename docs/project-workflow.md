# Semester project workflow

1. Start the API and inspect `/api/health` and `/docs`.
2. Create an account, upload a research PDF, and wait for indexing.
3. Ask a paper-specific question and inspect each cited page excerpt.
4. Ask about information absent from the paper and confirm the assistant abstains when retrieval is weak.
5. Upload multiple papers to use comparison, literature review, and research-gap suggestions.
6. Record questions, expected pages, and review notes before reporting retrieval metrics.
