# Evaluation

Do not publish scores until a human-labeled question set exists. For retrieval, use Hit@K, mean reciprocal rank (MRR), and expected-page hit rate. Review generated answers for factual support, citation correctness, completeness, and refusal behavior. Include out-of-scope questions to check that the similarity threshold causes an abstention. Preserve the PDF version and annotation notes alongside benchmark results so scores can be reproduced.
